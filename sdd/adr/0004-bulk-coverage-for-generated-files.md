# ADR-0004: Bulk glob coverage for generated / fixture files in IMPACT docs

- **Status:** accepted
- **Date:** 2026-06-13
- **Deciders:** project owner + maintainer
- **Spec / REQ touched:** cross-cutting (SDD harness)

## Context
The per-directory `IMPACT.md` convention requires every file in a tracked directory to be
documented. For source code this is valuable (blast-radius reasoning). But for `examples/`,
each new diagram type adds a hand-authored `<type>.psyuml` **and** a *generated* `<type>.svg`
golden, and the checker forced a hand-edited row per file. The `.svg` goldens are generated by
tests and byte-compared in CI, and every `.psyuml` is validity-gated by the examples-corpus
lint — so a per-file documentation row added no information and was pure, repeated friction
that slowed every diagram increment.

## Decision
Add an opt-in **`<!-- sdd:cover: <globs> -->`** directive that an `IMPACT.md` may declare; any
file matching a covered glob (`*.ext`, `prefix*`, or exact name) counts as documented in bulk.
Applied to `examples/` (`*.psyuml`, `*.svg`). Source files are **still enumerated** — coverage
is intended only for generated artifacts and homogeneous fixtures, so blast-radius docs for real
code remain mandatory.

## Consequences
- **Positive:** adding a diagram example no longer requires an `IMPACT.md` edit; the directory is
  still documented (purpose, deps, blast radius, file-category description), and validity stays
  enforced by the corpus lint + golden compare. Removes the main standing tax of the harness.
- **Negative / cost:** a directory could over-use coverage to skip documenting real source. Guard
  it by convention (the directive's comment + this ADR say "generated/fixtures only").
- **Impact:** `sdd/check.mjs` (new `extractCovers`/`matchesCover`), `sdd/README.md`,
  `sdd/templates/impact.md`, `examples/IMPACT.md`.

## Alternatives considered
- **Keep per-file rows.** Rejected — pure busywork for generated goldens; slowed every increment.
- **Drop `IMPACT.md` from `examples/` entirely.** Rejected — the directory still deserves a
  purpose + blast-radius doc; only the per-file enumeration was the problem.
- **Stop committing goldens (generate in CI only).** Rejected — committed goldens make renderer
  changes reviewable as diffs and let `apps/web` import them.
