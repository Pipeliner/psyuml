# ADR-0015: v0.2 M12 — realizing Pattern semantics + provenance/confidence (the concrete model + render choices)

- **Status:** accepted
- **Date:** 2026-06-15
- **Deciders:** project owner + maintainer
- **Spec / REQ touched:** v0.2 §3, §4 / REQ-PATTERN-SEMANTICS, REQ-PROVENANCE-CONFIDENCE (extends ADR-0014)

## Context
ADR-0014 set the v0.2 direction; M12 is the first slice that touches the **model** and a
**renderer**. The spec (v0.2 §3/§4) calls for CAT-derived loop topologies (trap/dilemma/snag),
exits-as-intervention, ontology-neutral internal nodes, and provenance+confidence as two
orthogonal first-class axes (adding `contested`). Several concrete realization questions had
real forks — worth recording because M13 (audience rendering + editor) builds directly on them:

1. **Where does the §3 "provenance" axis live?** v0.1 already has a `provenance: string[]`
   (school tags) *and* an `epistemicStatus` enum. The spec says the new axis
   "subsumes/aligns with v0.1 `epistemicStatus`."
2. **Where does the loop topology live** — a diagram-level field, an edge field, or a node tag?
3. **How is the "as-if" qualifier modeled** without baking in a metaphysics of mind?
4. **How is all of this rendered** so meaning never rests on colour or a glyph alone (§D, §5
   Tier-A), and **without churning** the overlap invariant (ADR-0012) or the v0.1 goldens?

The hard constraint throughout: **additive and backward-compatible** (MINOR semver) — a plain
v0.1 loop must render byte-identically.

## Decision
1. **Extend `EpistemicStatus`** with `jointly-agreed`, `clinician-inferred`, `contested` rather
   than adding a parallel field. This honours the spec's "subsumes v0.1 epistemicStatus", avoids
   a confusing second provenance field next to the existing `provenance: string[]` school tags,
   and is additive (no v0.1 value removed). Confidence (L/M/H) already exists — left as-is.
   A shared `INTERPRETIVE_STATUSES` set + `isInterpretive()` predicate is the **single source of
   truth** for the descriptive-vs-interpretive split (so render and any future lint agree).
2. **`Edge.loopTopology`** (`trap`/`dilemma`/`snag`) — a top-level edge field, parallel to the
   existing `loop: 'R'|'B'`. Tag the edge that closes/defines the loop. (Not diagram-level: a
   model can hold more than one loop; not a node tag: the topology is a property of the cycle.)
3. **`Properties.asIf: boolean`** — an ontology-neutral "as-if/metaphor" flag on the node, so an
   internal node can be named *as if* it were an agent/part/voice without asserting that
   metaphysics. Reciprocal-role / observing-eye stay *optional* `stereotype` tags (CAT dialect).
4. **Rendering (`renderLoopMap`), all additive:**
   - A **centre loop-topology marker**: a distinct monochrome glyph per topology **plus a
     redundant uppercase word** (TRAP/DILEMMA/SNAG) — never glyph- or colour-only. Drawn in the
     open ring centre (no overlap-invariant impact; untagged decoration).
   - **Interpretive content → dashed border**, descriptive → solid (the v0.1 convention the spec
     §3 cites). Border-only ⇒ zero geometry change.
   - A **`contested` ⚖ marker** and an **`as-if` qualifier** are carried on the node's **own
     label** (owner content): they don't enlarge the node, so the universal label↔non-owner-node
     overlap rule is unaffected.
   - **Alt-text echoes everything** — topology + its plain-language meaning, contested/interpretive
     standing, confidence buckets (high/medium/low), and as-if framing — the redundant text channel.
5. **DSL parity:** `@psyuml/grammar` round-trips the new fields (`asIf=true`, `topology=…`, and the
   new `epistemic=` values) so the corpus round-trip invariant holds.

## Consequences
- **Positive:** the cat-sdr example now demonstrates the full v0.2 humility story (a trap loop;
  a contested, low-confidence, as-if reciprocal role drawn dashed) end-to-end; the
  descriptive/interpretive predicate is centralized; everything stays additive — only
  `cat-sdr.svg` changed, `process-loop.svg` and all other goldens are byte-identical.
- **Negative / cost:** `EpistemicStatus` now carries both "source" and "standing" flavours
  (e.g. `inferred` vs `clinician-inferred` overlap) — accepted to match the spec and avoid a
  parallel field; a future MAJOR could split the axes. The topology glyphs are *placeholders*
  pending the M14 participatory + ISO-9186 comprehension gate — they are distinguishable and
  word-redundant, not yet validated. Contested/as-if markers ride the label, so on a very dense
  ring they lengthen wrapped text (bounded by `maxWidth`); the editor authoring UI is M13.
- **Impact:** `packages/model/index.ts` (+ test), `packages/render/index.ts` (+ test),
  `packages/grammar/index.ts` (+ test), `examples/cat-sdr.psyuml` (+ regenerated `cat-sdr.svg`);
  traceability REQ-PATTERN-SEMANTICS, REQ-PROVENANCE-CONFIDENCE (in-progress).
  See `packages/model/IMPACT.md`, `packages/render/IMPACT.md`, `packages/grammar/IMPACT.md`.

## Alternatives considered
- **A new parallel `provenanceClass` field for the §3 axis.** Rejected — collides conceptually
  with the existing `provenance: string[]` (school tags) and contradicts the spec's
  "subsumes v0.1 epistemicStatus"; two near-synonymous fields would invite drift.
- **Loop topology as a diagram-level enum.** Rejected — a single model may express more than one
  maintaining loop; the tag belongs on the edge that defines its cycle.
- **A separate metaphysics enum (part/mode/ego-state/voice/role) baked into the model.** Rejected
  for M12 as over-committing — the ontology-neutral `as-if` flag + the existing free `stereotype`
  string keep the model school-neutral (spec §4/§6). Can be revisited if demand is real.
- **Per-node visual confidence pips / corner badges.** Deferred — risks overlap-invariant churn
  and clutter; alt-text + the dashed interpretive channel satisfy §3 now, visual confidence
  encoding can join the M14 comprehension-tested symbol set.
